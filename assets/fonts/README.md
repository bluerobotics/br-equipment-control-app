# Fonts

This directory contains custom fonts bundled with the application.

## Cascadia Code

**Cascadia Code** is Microsoft's open-source monospace font designed for coding.
- License: SIL Open Font License 1.1
- Source: https://github.com/microsoft/cascadia-code
- Used for: All UI text in the application for cross-platform consistency

To download the latest version:
1. Visit https://github.com/microsoft/cascadia-code/releases
2. Download the latest `.ttf` files
3. Place `CascadiaCode-Regular.ttf` and `CascadiaCode-Bold.ttf` in this directory
